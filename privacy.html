Privacy Policy

Yosef ClipForge ("the tool") is a personal, self-hosted application that runs on its owner's own computer. This policy explains what data it handles.

What data is handled

  • Account connection data - when the owner connects a TikTok account, the tool receives an access token, a refresh token, and basic profile info (open ID, display name, avatar) via TikTok Login Kit with the user.info.basic scope.
  • Videos and captions - the owner's own clips and the captions written for them, sent to TikTok via the Content Posting API (video.upload, video.publish) only when the owner chooses to publish.

Where it is stored

All data stays on the owner's own computer. Access tokens are stored encrypted (AES-256-GCM) in a local database. Nothing is sent to any server other than the official APIs of the platform being published to.

Sharing

No data is sold, shared with third parties, or used for advertising or analytics. The tool has no tracking and no other users.

Retention and deletion

Disconnecting an account inside the tool deletes its stored tokens and profile info. Access can also be revoked in TikTok under Settings and privacy → Security & permissions → Manage app permissions. Deleting the tool's data folder removes everything.

Contact

Privacy questions or deletion requests: open an issue on GitHub.
